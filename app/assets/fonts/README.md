# Bundled icon font

`Phosphor-Regular.ttf` is the regular weight of the Phosphor icon family, distributed under the
MIT license. It was sourced from [`egui-phosphor` 0.14.0](https://github.com/amPerl/egui-phosphor),
which bundles the upstream Phosphor font for egui applications. The font is embedded into native
and WebAssembly builds. See [LICENSE-MIT](LICENSE-MIT).
