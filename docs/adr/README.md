# Architecture decision records

ADRs record choices that affect code boundaries, supported formats, and long-term product direction.
Read the rationale before changing a boundary; write a new ADR when a decision is superseded.

| ADR | Decision |
|-----|----------|
| [0001 — Single portable binary](0001-single-portable-binary.md) | Ship one portable desktop executable per platform. |
| [0002 — Windows shell integration](0002-windows-shell-integration.md) | Keep shell integration best-effort and isolated from core document behavior. |
| [0003 — Defer format and timeline features](0003-defer-format-and-timeline-features.md) | Prioritize reliable raster/vector editing before broad format and timeline expansion. |
