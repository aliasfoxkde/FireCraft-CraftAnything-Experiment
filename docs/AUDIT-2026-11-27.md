## Architecture review and design trail

The architecture skill report is available at `/tmp/architecture-review-20261127.html`. It ranks these candidates:

1. **Canvas interaction policy seam** — `app/src/canvas.rs` mixes egui input, coordinate conversion, tool gates, and editing effects; `app/src/app.rs` owns tool-dependent transitions. Recommendation: isolate normalized interaction behavior while keeping `Document` ownership in `FireCraft`. Start here if selected.
2. **Format codec / file adapter seam** — `app/src/formats.rs` combines path I/O with encode/decode behavior despite the existing `FileService` orchestration seam. Deepen only if memory-based codec tests remove disk setup from format behavior tests; do not add another path adapter.
3. **Panel-body locality** — retain the existing `PanelDescriptor` registry and extract only a cohesive behavior family from `panels/bodies.rs` when state and tests become materially more local.

No new glossary term or ADR was needed. Existing glossary terms (Document, Page, Layer, Object, God view) and ADRs were checked. Candidate 1 awaits maintainer selection; no interface was proposed in the report.
