# FireCraft Tutorials

Task-oriented guides for FireCraft, a clean-room reimplementation of Adobe
Fireworks CS6. Start here if you are new; the reference tables live in
[Keybindings](keybindings.md).

| Tutorial | What you learn |
|----------|----------------|
| [Getting Started](getting-started.md) | Launch the app, create a document, understand the workspace |
| [Drawing & Editing](drawing-and-editing.md) | Vector shapes, bitmap tools, paths, selection |
| [Working with Pages & States](pages-and-states.md) | Multi-page documents and animation frames |
| [Optimize & Export](optimize-and-export.md) | Slice, preview, and export web graphics |

All tutorials assume the default workspace. Reset with **Window → Workspace →
Reset Panels** if your docks have been rearranged.
