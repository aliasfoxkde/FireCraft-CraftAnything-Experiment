# Tutorials

Each tutorial should teach one outcome from a real application run. The current pages cover the
first-pass learning path; they are still missing consistent verified screenshots and a complete
workflow-evidence map. That work follows the
[Documentation and workflow evidence process](../DOCUMENTATION-AND-WORKFLOW-EVIDENCE.md).

## Learning path

| Tutorial | Outcome | Before you begin | Related reference |
|----------|---------|-----------------|-------------------|
| [Getting Started](getting-started.md) | Open the app, create a document, and recognize the workspace | Launch the current build | [Keybindings](keybindings.md), [Feature Surface](../features/README.md) |
| [Drawing & Editing](drawing-and-editing.md) | Create and edit vector shapes, bitmap marks, and paths | Complete Getting Started | [Infinite Canvas](../features/infinite-canvas.md), [keybindings](keybindings.md) |
| [Working with Pages & States](pages-and-states.md) | Organize a multi-page document and animation states | Create a document | [Feature Surface](../features/README.md) |
| [Optimize & Export](optimize-and-export.md) | Preview and export a web graphic | Complete a small design | [File Browser](../features/file-browser.md) |
| [Keybindings](keybindings.md) | Look up the current keyboard shortcuts | None | [Accessibility checklist](../A11Y.md) |

## Evidence status

The tutorials are not yet comprehensive, and most do not include tested screenshots or sample
projects. Do not infer that a written procedure has passed end-to-end validation. The workflow plan
tracks which pages need an automated browser/desktop scenario, a manual Windows check, screenshots,
and reviewer sign-off.

## Workspace note

The current lessons use the default workspace. If panels were rearranged, restore it with **Window →
Workspace → Reset Panels** before following steps; later tutorials will record the starting layout
in their workflow manifest.
