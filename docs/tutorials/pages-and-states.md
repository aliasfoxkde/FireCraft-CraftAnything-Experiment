# Working with Pages and States

## Pages

A FireCraft document holds multiple pages, each with its own layers and
objects — like sheets in one file. The **Pages** panel (**F5**) lists them.

- Click a page to switch. **PageUp/PageDown** steps through pages.
- Double-click a page name to rename it.
- The panel header icons add, duplicate, and delete pages.

## States (animation frames)

Each page can hold multiple *states* — the frames of an animation. The
**States** panel sits in the same group as Pages (Shift+F2 focuses it).

- Add states with the panel's New button; each state copies the page's
  layers (you choose share/no-share).
- **Home/End** jump to the first/last state; the transport controls in the
  status bar play/stop the animation and set the frame delay.
- Onion-skinning is available from the States panel menu.

See [Optimize & Export](optimize-and-export.md): choose GIF, and the export
