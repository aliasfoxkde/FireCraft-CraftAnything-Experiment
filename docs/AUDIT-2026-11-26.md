# Repository audit — 2026-11-26

**Repository:** `FireCraft-CraftAnything-Experiment`
**Branch / audited base:** PR head `8b0084e4e8fd89619ef4b6e3dca894d6a91f5583` on `codex/v0.3.0-release-prep`, based on `main` at `dab457c233779a97d9b5b80f85642d16ed6dc663`; later release-gate fixes are tracked in this PR branch.
**Version:** `app/Cargo.toml` 0.3.0; the public latest release at audit time is v0.2.0.
**Purpose:** evidence snapshot for the implementation and release work in this branch. The measurements below were collected against the changed working tree; remote GitHub run/PR state is at the cited times and may change.

## Executive assessment

The editor now has a substantial native and WASM feature surface and a useful command/test harness, but it is **not release-certified across platforms**. On the current working tree, 131 automated tests pass, strict Clippy passes, the WASM target compiles, coverage has been rerun, and the docs/module-size/package-script/workflow static gates pass. Six Xvfb GUI capture states and Wine CLI smoke are also recorded from this pass. The updated Windows GNU executable works under Wine, but this is not Windows 11 GUI acceptance. The previous claim that the Properties control worked was too strong: a full-width double-click hit target shadowed the chevron. That root cause is now fixed and guarded by an actual one-click hit-test regression.

Measured LLVM coverage is **51.51% lines / 56.28% functions** (region coverage 51.23%), not 99%. Coverage is uneven: `harness.rs` is 97.48%, `doc.rs` 90.17%, `menus.rs` 76.32%, `formats.rs` 74.78%, `layout.rs` 44.54%, `panels/mod.rs` 50.56%, and `icons.rs` 22.28%. Documentation quality is not a meaningful single “percent coverage” metric; it needs link validation, feature-to-doc mapping, and claim-to-evidence checks. The requested 99% target is now tracked as independent goals in the active task ledger; it is not yet achieved. WCAG 2.1 AAA conformance has not been measured. The current theme tests establish selected text contrast at AA thresholds only.

Publishing v0.3.0 is gated by a reliable exact-tag workflow and platform receipts. The then-current GitHub workflows failed before any job step appeared; six open Dependabot PRs showed the same failure shape. Local GitForge was degraded and its active runner build was 273 commits behind local `origin/main`. Neither signal qualifies as a green production pipeline.
